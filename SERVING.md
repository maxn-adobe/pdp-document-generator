# Serving this tool via AEM Edge Delivery + da.live

This repo is a standalone Vite/React tool (it does **not** use the EDS content pipeline). It is served as static files from the Edge Delivery **code bus** and embedded in da.live as an app.

## URLs

- **In da.live (primary):** https://da.live/app/maxn-adobe/pdp-document-generator/index
- **Direct (delivery):** https://main--pdp-document-generator--maxn-adobe.aem.live/index.html

## How it works (the parts that matter)

- **Two kinds of files:** *code* (this repo's built files, mirrored to the code bus by AEM Code Sync) vs *content* (authored docs — not used by this tool).
- **Two tiers:** a **preview** tier (`…aem.page` / `…preview.da.live`) and a **live** tier (`…aem.live`).
- **da.live embedding:** `da.live/app/{org}/{repo}/{path}` loads the "Nx Shell", which iframes `https://{ref}--{repo}--{org}.preview.da.live/{path}.html` and injects the DA auth token via `nx/utils/sdk.js`.

## Why the entry is at the repo ROOT (not `/dist`)

The Nx Shell loads from the **preview** tier (`preview.da.live`). That tier serves the **root** `/index.html` and `/dist/assets/*`, but does **not** serve a subfolder `/dist/index.html`. So the built HTML entry must live at the repo root:

- `index.dev.html` — the Vite source template (used for `npm run dev` and as the build entry).
- `index.html` (root) — the **built** entry, generated by `npm run build` (see `scripts/postbuild.mjs`). References `/dist/assets/*`. Do not hand-edit.
- `dist/assets/index.js`, `dist/assets/index.css`, `dist/favicon.svg` — built assets (committed).

`npm run build` compiles to `dist/assets/`, then copies the built HTML to `./index.html`.

## One-time setup (for reference / re-creating on another repo)

1. Add `fstab.yaml` at the repo root, on the default branch (`main`).
2. Register the EDS site **once** via the Admin API:
   ```
   PUT https://admin.hlx.page/config/maxn-adobe/sites/pdp-document-generator.json
   x-auth-token: <token from an admin.hlx.page/auth/adobe login>
   {"code":{"owner":"maxn-adobe","repo":"pdp-document-generator"},
    "content":{"source":{"url":"https://content.da.live/maxn-adobe/pdp-document-generator/","type":"markup"}}}
   ```
3. Install **AEM Code Sync** on the repo. If it isn't syncing (no commit activity; delivery returns `code-bus: 404`), **remove + re-add** the repo in the app's settings to force the initial sync.

## Troubleshooting (read the `x-error` response header)

```bash
curl -sS -D - -o /dev/null "https://main--pdp-document-generator--maxn-adobe.aem.live/index.html" | grep -i "x-error\|HTTP/"
```

| `x-error` | Meaning | Fix |
|---|---|---|
| `Missing configuration` / `no such site` | Site not registered | Do setup step 2 |
| `failed to load … from code-bus: 404` | Registered, code not synced | Re-add repo in Code Sync (step 3) |
| `failed to load /index.md from content-bus: 404` (on `/`) | Healthy — config resolves, no homepage doc | n/a |
